### 🧭 What I do

I help agile teams ship releases with more confidence and fewer surprises in production. In practice, that means:

- 🧪 **End-to-end automation** with **Cypress** (JavaScript/TypeScript) for web flows — expanding regression coverage and cutting rework release after release.
- 🔌 **REST API testing** with **Postman**, cross-checked against **PostgreSQL** and **Firebase** — because a backend bug doesn't always show up on the screen; it shows up in the data.
- 🔍 **Root-cause analysis** and bug reports a developer understands on the first read — no more *"couldn't reproduce it"* back-and-forth.
- 🤝 Working with **product and engineering from refinement onward**, catching failures before they even reach development.

I once walked into a company with **no QA process at all** and built the first one from scratch — fewer rollbacks, more stability, a team sleeping easy on deploy day.

---

### 🎬 Where the instinct comes from

Before code, I spent years in **audiovisual production** working with image and data integrity — environments where there's no cheap *"let's shoot it again."* Being the last line of defense before an error becomes irreversible was already the job. I moved into tech and found the game is exactly the same. Only the screen changed.
